## 3. 지금 게임에 들어가 있는 것 (메인씬 테스트)
### 규칙
- 죽으면 **마지막 체크포인트 이후에 바뀐 것만** 되돌림: 깬 X벽·C바닥, 먹은 항체(더블점프), 잡은 몬스터, 웨이브 방, 감염핵·노란 문, 함정 2 B 매복. 나노 캡슐은 영구.
  (`CheckpointResetManager` + `ResettableBehaviour`. GameFlowManager의 `reloadSceneOnRespawn`을 이 씬에서만 꺼 둠)
- 부활하면 플레이어 크기를 씬 크기(2.44)로 되돌림 (팀원 GameFlowManager가 프리팹 크기로 만들기 때문).
### 기믹
- **X 백혈구 벽**(X로 깸) 6개, **C 백혈구 바닥**(C 내려찍기로 깸) 4개.
- **C 내려찍기**: 발판을 뚫고 가장 아래 바닥까지 박힘. 백혈구 바닥을 깨면 멈춤 없이 계속 내려감. (움직이는 혈소판·튕김 항체·백혈구 바닥은 안 뚫음) — `DivePassThrough`
- **C 튕김 항체** 3개 (작은 것 힘 13 ×2, 큰 것 27): 위에서 C로 찍으면 튕김 + 더블점프 충전, 그냥 밟으면 터지고 2초 뒤 다시 생김. 플레이어 착지 멈춤(프리팹 `fallingHitboxLingerTime` 1초)을 항체 위에서만 바로 끝내서 튕김이 됨.
- **항체(더블점프)**, **나노 캡슐 3개**(팀원 Nano capsule 프리팹).
- **웨이브 방** (x 92~109, 바닥 -21): 들어오면 위쪽 벽에서 감염된 벽이 자라나 잠김 → 빨간 "감염 반응 감지!" + 화면 테두리 빨간 깜빡임 → 웨이브 3번(뎅기3 / 간염3 / 뎅기2+간염2), 웨이브마다 "웨이브 N/3" + 3·2·1 + 소환 자리 보라 얼룩 → "정화 완료!" 후 벽이 들어감. 몬스터는 플레이어에게서 먼 자리부터. 바닥 높이는 시작할 때 스스로 찾음.
- **노란 문**(충돌 0.8 × 4) + **감염핵**(팀원 InfectionHeart): 감염핵을 부수면 문이 사라짐. 문 앞 안내 "감염핵을 제거하자".
- **몬스터 14마리** (방마다 설계대로), **함정 2 B 매복**(바닥에 내려서면 보라 얼룩 후 뎅기2·간염1, 보상 없음).
- 몬스터 프리팹: 인식 거리 뎅기·간염 모두 8, 간염 점프 약 6칸(4칸 떨어져서부터 뜀). 뎅기는 원래 점프 없음.
### 그림
- **바닥** = 중경_땅1·2 (밟는 면 맞춰 약 2칸씩 30조각, A→B 이어짐, 끝은 둥근 끝, 아래쪽은 어두운 색으로 페이드).
- **벽·천장** = 받은 땅 띠(Ground01~06을 이어 붙여 가운데 반복 + 양 끝). 얇은 땅은 그림을 줄이지 않고 두께 절반까지만 보이게 자름.
- **발판** = 적혈구, **혈소판** = 적혈구(감염된 것 보라), **부서지는 발판** = 적혈구(주황빛), **C 바닥** = 부서지는바닥, **X 벽** = 백혈구(세로).
- **튕김 항체** = foothold(작은 것) / foothold2(큰 것), 튕길 때 0→1→2→0 애니메이션.
- **감염핵** = 천장~바닥 높이로 키움, 바닥·천장 보라 감염 얼룩(부수면 같이 사라짐).
- **원경** = 메인씬 것 그대로 켬(흐림 그대로가 좋다고 결정). 땅 그림은 원경(-1000) 앞에 그림.
- HUD 왼쪽 위 캡슐 그림 숨기고 "×숫자"만.
- 아직 네모: **노란 문, 웨이브 감염벽, 혈류** (그림 기다리는 중).
