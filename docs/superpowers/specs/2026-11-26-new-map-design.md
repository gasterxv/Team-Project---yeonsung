# 새 맵 상세 설계 (메인씬 테스트)

작업 씬: `Assets/Scenes/메인씬 테스트.unity` (메인씬 복사 → 예전 맵 묶음은 꺼 둠)
좌표 단위: 유닛. 원점 = 시작 방 바닥 왼쪽 끝. 가운데 줄 바닥 윗면 = y 0.
방 좌표는 **안쪽 빈 공간** `[x0, x1] × [바닥 y, 천장 y]` 이다. 벽·바닥·천장은 땅 블록(두께 2.1)으로 그 바깥을 감싼다.

## 1. 진행 순서

1. 시작 → 초반 전투(X) → 완충(체크포인트 1) → 중앙 연결(C). 중앙 연결 오른쪽은 막힌 벽.
2. 중앙 연결 바닥(C) → 아래방 → 웨이브 → 감염핵. 감염핵 파괴 → 노란 문 열림.
3. 감염핵 → 웨이브 → 아래방 → 중앙 연결 → 수직 통로(부서지는 발판) → 노란 문 → 5 위쪽 혈류 복도(움직이는 혈소판 + 숨은 몬스터) → 하강 통로로 떨어져 4 보스 전 공간(체크포인트 2).
4. 4 → 3 중후반 점프맵을 **왼쪽으로** 깸 (더블점프 없이, C 내려찍기 항체 사용) → 높은 벽 너머 항체 칸 → 항체(더블점프) 획득 → **같은 점프맵을 오른쪽으로 다시 깨고** 4로 돌아옴.
5. 4 큰 C 튕김 항체 → 5 복도를 왼쪽으로 → 노란 문 → 수직 통로로 내려감 → 중앙 연결 → 완충 → 초반 → 시작 → 높이 5.5 턱을 더블점프 → 6 캡슐 방 → 나노 캡슐.
6. 시작 → 초반 → 완충 → 중앙 연결 → 수직 통로 → 노란 문 → 5 복도 → 낙하 → 4 → 7 보스방(입장 시 문 닫힘) → 보스 처치 → "몸이 치료되었다" → 출구 문 → 게임 클리어.
- 중앙 연결 ↔ 중후반 사이는 막힌 벽 (지름길 없음).

선택 경로: 시작 바닥(C) → 숨은 방 → 아래 캡슐 방, 완충 바닥(C) → 함정, 4 바닥(C) → 함정 2 A → 함정 2 B, 4 점프 발판 → 5 복도로 다시 올라가기.

## 4. 사망 시 초기화

- 마지막 체크포인트를 밟은 뒤에 바뀐 것은 **모두** 되돌린다: 깬 백혈구 벽·바닥, 잡은 몬스터, 웨이브 방, 감염핵(→ 노란 문 다시 닫힘), 항체(→ 더블점프 꺼짐), 부서지는 발판.
- 예외: 나노 캡슐. 한 번 먹으면 최대 개수가 영구히 +1.
- 저장은 체크포인트를 밟을 때만. 감염핵을 깬 뒤 자동 저장 없음 → 완충 체크포인트로 돌아가 저장하거나, 저장 없이 수직 통로·5 복도로 가다 죽으면 웨이브·감염핵부터 다시 (의도된 난이도).
- 구현: 새 스크립트 `CheckpointResetManager` — 체크포인트를 밟을 때 상태를 저장, `GameFlowManager.OnPlayerRespawn` 때 저장 상태로 되돌림.
