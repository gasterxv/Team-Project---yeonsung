2. 보스방



  • 지형 04, 지형 10~14 삭제 (붙어 있는 땅그림 포함)
  • 보스방 = x 239~303.5, 바닥 y0.94 ~ 천장 y19.3 (기존 43×12.2 → 64.5×18.4)
  • 천장 지형 03을 둘로 나눔: 왼쪽(x209.9~239)은 그대로, 보스방 부분만 y19.3로 올림
  • x282 오른쪽에 있던 것은 +21.5 이동, 바닥 지형 24는 x323.5까지 연장 (나중에 이어 만들 자리)
  • 입구 문: 플레이어가 입장 감지 영역에 들어오면 닫힘 / 출구 문: 처음부터 닫힘 / 보스 처치 시 둘 다 사라짐
  • 문 두 개에 BossRoomTacle 태그 → 보스 돌진이 문에 부딪혀 멈춤
  • 발판 2개 (방의 1/3, 2/3 지점, 바닥에서 2.2 위): 플레이어나 보스가 닿으면 1초 뒤 부서지고 20초 뒤 다시 생김 (그 자리에 누가 있으면 비킬 때까지 기다림)
  • 플레이어가 죽고 부활하면: 입구 문 다시 열림, 보스 체력과 위치 초기화, 발판 복구
