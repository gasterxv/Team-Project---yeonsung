## 1. 작업 규칙 (사용자가 정한 것, 꼭 지킬 것)

### 공통
- 설명은 한국어로.
- 커밋·푸시는 **사용자가 하라고 할 때만**. 작업 전에 `git status` 먼저 확인.
- `*.slnx` 같은 IDE 자동 생성 파일은 커밋하지 않음.
- 모르는 것, 애매한 것은 **추측하지 말고 무조건 물어보기**.
- 결과를 부풀리지 말 것. 확인 못 한 건 "확인 못 했다"고 말하기 (사용자가 "거짓말 안 하고"를 강조함).

### 씬 작업 규칙 (2026-11-23 사용자 지시)
- **Tools 메뉴 스크립트로 새 씬을 새로 만들지 말 것.** 팀이 이미 만든 기존 씬 안에서만 작업.
- 작업 전에 `Assets/Scenes`의 씬 목록과 각 씬에 무엇이 들어 있는지 먼저 보여주기.
- **Title 씬**: 사용자 씬이라 자유롭게 수정/삭제 가능. 끝나고 무엇을 바꿨는지만 알려주면 됨.
- **그 외 씬**(메인 씬 포함): 기존 오브젝트(카메라, 조명, 팀원이 넣은 것)는 바꿔도 되지만 **바꾸기 전에 무엇을 어떻게 바꿀지 먼저 물어볼 것**.
- **지우는 건 하지 말 것.** 씬, 오브젝트, 스크립트 전부. 필요 없어 보이면 목록만 알려주기. (그래서 지금까지는 "끄기(SetActive false)"나 SpriteRenderer 끄기로만 처리함)
- 오브젝트에 그림을 넣을 때:
  - 오브젝트 위치·크기·회전은 건드리지 않음 (단, 사용자가 "맵 오브젝트를 자르거나 붙여서 맞춰라"고 허락한 경우는 예외 — 아래 5장 참고)
  - 먼저 "오브젝트 이름 → 넣을 그림 파일" 매칭 표를 보여주고 확인받은 뒤 넣기
  - 이름만으로 애매하면 물어보기
  - 그림 비율이 오브젝트와 안 맞으면 **늘리지 말고 알려주기**

### 이미지 Import 규칙
- 사용자가 올린 `Assets/image/` 파일만 Import 설정을 바꿈. 다른 팀원 파일(`Assets/Resources/맵/...`, coaak가 올린 `감염핵.png`, `부서지는바닥.png`, `Resources/UI/*` 버튼 그림 등)은 Import 설정 포함 **건드리지 않음**.

## 2. 기획서 요약 (맵 관련)

- 장르: 메트로베니아 / 대쉬 회피 액션, 할로우 나이트풍 2D 다크 판타지
- 세계관: 몸속 바이러스를 마이크로로봇(박테리오파지)으로 토벌. 혈관 → 폐 → 신경계 → 소화계 → 심장
- 조작: ←/→ 이동, ↑ 점프, X 공격, C(공중) 특수공격(낙하), Space 대쉬, F 회복/상호작용
- **순환계-튜토리얼 구역** 구성
  1. 시작 혈관(평평한 길, 조작 안내) 2. 기본 점프(낮은 장애물, 작은 구덩이) 3. 기본 전투 4. 낙하 특수공격(높은 발판 아래 몬스터) 5. 종합 테스트
  6. **혈류 점프맵**: "혈관 하단에는 빠르게 흐르는 혈류가 존재하며, 플레이어가 접촉하면 피해를 입음. 혈류 위에는 적혈구가 발판으로 배치되어 있고, 플레이어는 이를 밟고 앞으로 이동." Space 대쉬로 몬스터 회피 연습
  7. 감염 핵 구역: 숨겨진 감염 핵을 처치하면 혈관 문이 열림. 문 근처에서 "감염 핵을 제거하고 오자." 문구. 보스방 직전 체크포인트, F로 체력 회복 안내
  8. 튜토리얼 보스(혈전): 처치 시 보스방 중간에 항체(이단 점프), 죽은 자리에 백신(감염된 혈관 문 열쇠)
- 오브젝트: 적혈구(A 고정형 / B 좌우 왕복형 발판), 백혈구(고정형 발판, 적혈구 크기의 1.5배 — 지금은 장식 취급), 부서지는 바닥(위에서 특수공격하면 파괴), 감염된 문(위/아래 두 파트로 열림)
- 기획서 46쪽 중 오브젝트 표(18쪽) 마지막 줄에 흐르는 빨간 화살표 그림 = 혈류 오브젝트로 추정 (썸네일 글씨가 깨져서 수치는 못 읽음)

## 5. 메인 씬(`#MainScenes#`)에서 한 일

도구: `Assets/Editor/MainSceneArtApply.cs` → 메뉴 **Tools > 메인씬 그림 넣기** (열린 `#MainScenes#`만 수정, 저장은 안 함, Ctrl+Z 한 번으로 되돌림, 이미 적용됐으면 `땅그림_v2`를 보고 멈춤)

### 5-1. 적혈구 발판 (사용자 승인)
- 대상: `설계도 지형`의 지형 30, 31, 38~59
- 적혈구 그림(1137×451, 비율 2.52:1)에 맞춰 발판 **가로를 2.35로 자름**(가운데 기준, 콜라이더도 같이). 위치·높이는 그대로
- 지형 31(8.0 길이)은 적혈구 3개로 나눔: 원래 오브젝트 = 가운데, `지형 31-2`, `지형 31-3` 새로 추가
- 원래 회색 SpriteRenderer는 끄기만 함, 그림은 자식 `그림`

### 5-2. 빨간 블록에 땅 그림 (사용자 승인, 여러 번 수정됨)
- 대상: 지형 01~29, 32~37 (벽과 천장 01~14 포함, 사용자 선택: "벽과 천장까지 전부")
- 최종 방식(v2):
  - 같은 높이 + **서로 붙어 있는 블록끼리 한 줄(run)**로 묶어 그림을 길게 이어 깔고, 블록 모양 **Sprite Mask**(Custom Range)로 파냄 → 구덩이에서만 끊겨 보임
  - 그림 종류는 줄마다 **AI 타일 → 땅1 → 땅2** 순서로 돌아감 (사용자 선택: "구덩이에서 바꾸기")
  - AI 타일은 한 장 건너 **좌우 반전**해서 같은 무늬가 그대로 연속되지 않게
  - 땅1/땅2는 둥근 양 끝 200px을 sprite border로 두고 Tiled로 가운데만 반복, 둥근 끝은 블록 밖(3유닛)으로 뺌
  - 블록이 그림보다 깊은 부분은 그림 아랫부분과 같은 색의 `땅바탕`으로 채움 (세로로 쌓으면 줄무늬가 생겨서)
  - 마스크 위쪽 여유 0.6 (윗선 위 혹이 잘리지 않게)
  - 벽과 천장은 그림을 위아래 뒤집어 검은 선이 아래(플레이어 쪽)로
  - 이전 버전 결과(`땅그림_이어붙임`, 블록마다 `땅마스크`/`땅바탕`)는 지우지 않고 **꺼 두고 이름 뒤에 `(이전)`** 붙임
- 정렬 순서: 땅 그림 -10부터 줄마다 -3씩, 혈류 -800, 원경 -1000/-1001

### 5-3. 혈류 (사용자 승인, 기획서 기준)
- 바닥이 없는 낭떠러지 3곳 = 혈류 구간: x **70.03~83.90**, **106.0~125.73**, **143.59~202.59**
  - x 28.2~35.7 작은 구덩이는 바닥(지형 16)이 있어 "점프 연습용"으로 보고 제외
- `설계도 지형/혈류 1~3`: 표면 y -2.5, 두께 0.8 트리거 + `BloodFlow`(대미지 1, 위로 튕김 bounce 11, 오른쪽으로 밀림) + 아래 단단한 바닥(`혈류 N 바닥`, y -5까지)
- 혈류 그림이 아직 없어서 빨간 반투명 사각형 + 흐르는 줄무늬로 자리만

### 5-4. 배경 (사용자 승인)
- `원경_배경`(씬 루트 맨 앞): 튜토리얼에서 쓰던 블러 원경 `image/원경1.PNG`, `원경2.PNG` + `ParallaxTile`(0.6, 반복 주기 38.4). Play 중에만 카메라를 따라 움직임(Scene 뷰에서는 일부만 보이는 게 정상)

5. 이 세션에서 규칙 전에 삭제한 메인씬 오브젝트(12-1의 삭제 목록)를 복구할지.
6. 원래 정하기로 한 브랜치 `map-rework`는 만들지 않았음. 지금은 `minjae-work`(= `map-rework-school` 기반)에서 작업 중 — 이 이름으로 계속 쓸지.

### 12-6. 작업 방식 메모 (도구)

- **씬 확인**: 씬 YAML을 C# 스크립트(`dotnet run scene.cs`)로 파싱해 오브젝트 월드 좌표·콜라이더 범위를 뽑아 검증했음 (로컬 스크래치패드에만 있었음 → 필요하면 다시 작성).
- **미리보기**: 콜라이더 좌표로 SVG 지도를 그려 "지금 / 수정안"을 HTML로 보여주고 승인받음 (예: `docs/superpowers/specs/map-changes-preview.html`).
- **씬 적용**: 씬 YAML을 직접 고치지 않고 **에디터 메뉴 스크립트(Tools > 메인씬 > …)**를 만들어 사용자가(또는 Unity 화면 조작으로) 한 번 실행 → Ctrl+S. 이유: `설계도 지형`이 CompositeCollider2D라 YAML 직접 수정 시 충돌 모양이 어긋날 수 있음. Ctrl+Z 한 번으로 되돌릴 수 있게 Undo 그룹 사용.
- **컴파일 확인**: `dotnet build Assembly-CSharp-Editor.csproj` (출력은 레포 밖으로). Unity가 만든 csproj는 새 파일을 모르므로 새 `.cs`는 csproj에 임시로 추가해서 빌드. csproj는 gitignore.
- **플레이 확인**: 로컬에선 computer-use로 Unity를 직접 조작(Play, 방향키, Inspector에서 위치 이동, 일시정지 후 위치 변경). 짧은 키 입력은 씹혀서 `hold_key` 0.1~0.4초 사용. **클라우드 세션에서는 Unity 실행·플레이 확인이 불가** → 확인은 사용자에게 요청.
- 씬 파일은 CRLF 줄바꿈. 일부 기존 스크립트는 cp949 인코딩 (예: `ThrombusBoss.cs`, `VaccineGate.cs`) — Edit 도구로 못 고치니 주의.
