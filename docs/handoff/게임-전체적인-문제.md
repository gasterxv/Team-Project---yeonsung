## 2. 작업 규칙 (사용자가 정한 것, 꼭 지킬 것)

1. 새 씬 만들지 말 것. 기존 씬 안에서만. (예외: 다른 세션이 이미 만든 `MainScene_Rework.unity`, `메인씬 테스트.unity` — 사용자와 상의해서 쓰는 중)
2. `Title` 씬은 사용자 씬이라 자유롭게 수정 가능. 끝나고 뭘 바꿨는지만 보고.
3. 그 외 씬(특히 `Assets/Scenes/#MainScenes#.unity`)은 **바꾸기 전에 무엇을 어떻게 바꿀지 먼저 물어볼 것**.
4. **지우지 말 것** (씬, 오브젝트, 스크립트, 이미지 전부). 필요 없어 보이면 목록만 알려주고, 필요하면 비활성화만.
5. 팀원 파일 수정 금지: `image/감염핵.png`, `image/부서지는바닥.png`(coaak), `Assets/Resources/맵/` 전체, 팀원 스크립트(`BreakableFloor`, `BreakableFloorSlamReceiver`, `InfectionHeart` 등). 컴포넌트로 붙여 쓰는 건 OK.
6. 커밋·푸시는 **사용자가 하라고 할 때만**. `*.slnx` 등 IDE 자동 생성 파일은 커밋 금지.
7. 병렬 작업 금지 (같은 씬 파일 충돌).
8. 버그 수정은 `superpowers:systematic-debugging`으로 원인부터.
9. 작업 끝나면 `superpowers:verification-before-completion`으로 실제 확인(컴파일, 씬, 스크린샷) 후 보고.
10. 사용자가 "대화만 하자"고 하면 파일 절대 수정 금지.
11. 모르거나 애매하면 **추측하지 말고 물어볼 것**.

추가로 이 세션에서 굳어진 사용자 선호:
- **맵을 고치기 전에 반드시 그림(미리보기)으로 먼저 보여주고** 승인받은 뒤 적용. ("작업하기 전에 이런 건 싹 다 말하고 수정하자, 맵도 이미지로 보여줘")
- 사소해 보이는 것도 전부 미리 말하기.
- 플레이 피드백은 "수정이 맞는지 확인"이 아니라 **플레이어 입장에서 이상한 것 / 쉬운 것 / 좋은 것**.

## 5. 직접 플레이(Unity 화면 조작)로 찾은 문제

1. **보스가 안 움직임** — 보스 `groundLayer` = `Ground`(512)인데 지형(`설계도 지형` 컴포지트)은 `Default` 레이어 → 로그 `바닥=없음`, 점프 이동·패턴 안 나옴. 몬스터 경고 "Attack Ground Layers에 실제 바닥 레이어를 지정하세요"도 같은 원인 추정. **새 맵 지형은 `Ground` 레이어로** (사용자 답 대기, 6번 참고).
2. 몬스터 스폰 15개와 부모 `설계도 몬스터 스폰`이 꺼져 있음 → 첫 몬스터 외엔 없음 (사용자: 몬스터는 나중에).
3. 체력 UI 안 보임, 작은 검은 사각형이 화면에 떠 있음 → 이후 `e236060`에서 체력바 UI 추가됨 (재확인 필요).
4. 공격 이펙트 안 보임 (사용자: 나중에).
5. "[항체] 보스 처치 후 드롭"이 처치 전부터 보임.
6. 첫 몬스터(간염, HP 100, 공격당 10) 너무 셈 → 시작하자마자 3번 사망.
7. 첫 체크포인트가 x 102로 너무 멀고 그 전에 즉사 혈류 2개.
8. 계단 꼭대기에서 뛰면 안 보이는 혈류로 떨어짐 (사각지대).
9. 카메라가 플레이어를 가운데 두고 세로 10칸만 보여서, 점프할 때 아래 발판이 화면 밖.

## 6. 정한 것 (새 맵)

- 맵은 거의 새로 깐다. 최신 설계: `docs/superpowers/specs/2026-11-26-new-map-design.md` (방 좌표, 진행 순서, 새 스크립트 목록 포함).
- 흐름: 맵 진행 중 **더블점프 항체** 획득 → 처음 위치로 걸어서 돌아와 **나노 캡슐** 획득 → 비교적 쉽게 보스전. (걸어서 돌아가는 건 의도)
- 방 사이 막힘 = 백혈구(X로 부숨), 바닥 막힘 = 부서지는바닥/백혈구 바닥(C로 부숨).
- 혈류 = 즉사 → 마지막 체크포인트 부활.
- 보스방: 예전 "1.5배" 취소. **한 화면 안에 들어오는 크기** (설계 문서에선 19.2 × 10.8). 크기는 사용자에게 꼭 확인.
- 보스방 부서지는 발판 2개 (1초 뒤 부서짐, 20초 뒤 복구, 겹치면 대기).
- 땅 블록: 원본 땅의 둥근 양 끝 + AI 땅 가운데 반복, 한 블록은 같은 원본만, 세로 반복 금지, 콜라이더는 보이는 윗면에 맞춤. **샘플 1개 먼저 보여주고 승인 후 확대.** (도구 `Editor/NewGroundBuilder.cs`는 다른 세션이 만듦)
- 타이틀: `Title_illustration` 꽉 채우고 왼쪽 어두운 곳에 로고(임시) + Game Start / Setting / Quit.

## 9. 작업 방식 메모 (도구)

- **씬 확인**: 씬 YAML을 C# 스크립트(`dotnet run scene.cs`)로 파싱해 오브젝트 월드 좌표·콜라이더 범위를 뽑아 검증했음 (로컬 스크래치패드에만 있었음 → 필요하면 다시 작성).
- **미리보기**: 콜라이더 좌표로 SVG 지도를 그려 "지금 / 수정안"을 HTML로 보여주고 승인받음 (예: `docs/superpowers/specs/map-changes-preview.html`).
- **씬 적용**: 씬 YAML을 직접 고치지 않고 **에디터 메뉴 스크립트(Tools > 메인씬 > …)**를 만들어 사용자가(또는 Unity 화면 조작으로) 한 번 실행 → Ctrl+S. 이유: `설계도 지형`이 CompositeCollider2D라 YAML 직접 수정 시 충돌 모양이 어긋날 수 있음. Ctrl+Z 한 번으로 되돌릴 수 있게 Undo 그룹 사용.
- **컴파일 확인**: `dotnet build Assembly-CSharp-Editor.csproj` (출력은 레포 밖으로). Unity가 만든 csproj는 새 파일을 모르므로 새 `.cs`는 csproj에 임시로 추가해서 빌드. csproj는 gitignore.
- **플레이 확인**: 로컬에선 computer-use로 Unity를 직접 조작(Play, 방향키, Inspector에서 위치 이동, 일시정지 후 위치 변경). 짧은 키 입력은 씹혀서 `hold_key` 0.1~0.4초 사용. **클라우드 세션에서는 Unity 실행·플레이 확인이 불가** → 확인은 사용자에게 요청.
- 씬 파일은 CRLF 줄바꿈. 일부 기존 스크립트는 cp949 인코딩 (예: `ThrombusBoss.cs`, `VaccineGate.cs`) — Edit 도구로 못 고치니 주의.
