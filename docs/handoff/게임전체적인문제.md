## 2. 기획서 요약 (맵 관련)

- 장르: 메트로베니아 / 대쉬 회피 액션, 할로우 나이트풍 2D 다크 판타지
- 세계관: 몸속 바이러스를 마이크로로봇(박테리오파지)으로 토벌. 혈관 → 폐 → 신경계 → 소화계 → 심장
- 조작: ←/→ 이동, ↑ 점프, X 공격, C(공중) 특수공격(낙하), Space 대쉬, F 회복/상호작용
- **순환계-튜토리얼 구역** 구성
  1. 시작 혈관(평평한 길, 조작 안내) 2. 기본 점프(낮은 장애물, 작은 구덩이) 3. 기본 전투 4. 낙하 특수공격(높은 발판 아래 몬스터) 5. 종합 테스트
  6. **혈류 점프맵**: "혈관 하단에는 빠르게 흐르는 혈류가 존재하며, 플레이어가 접촉하면 피해를 입음. 혈류 위에는 적혈구가 발판으로 배치되어 있고, 플레이어는 이를 밟고 앞으로 이동." Space 대쉬로 몬스터 회피 연습
  7. 감염 핵 구역: 숨겨진 감염 핵을 처치하면 혈관 문이 열림. 문 근처에서 "감염 핵을 제거하고 오자." 문구. 보스방 직전 체크포인트, F로 체력 회복 안내
  8. 튜토리얼 보스(혈전): 처치 시 보스방 중간에 항체(이단 점프), 죽은 자리에 백신(감염된 혈관 문 열쇠)
- 오브젝트: 적혈구(A 고정형 / B 좌우 왕복형 발판), 백혈구(고정형 발판, 적혈구 크기의 1.5배 — 지금은 장식 취급), 부서지는 바닥(위에서 특수공격하면 파괴), 감염된 문(위/아래 두 파트로 열림)
- 기획서 46쪽 중 오브젝트 표(18쪽) 마지막 줄에 흐르는 빨간 화살표 그림 = 혈류 오브젝트로 추정 (썸네일 글씨가 깨져서 수치는 못 읽음)

도구: `Assets/Editor/MainSceneArtApply.cs` → 메뉴 **Tools > 메인씬 그림 넣기** (열린 `#MainScenes#`만 수정, 저장은 안 함, Ctrl+Z 한 번으로 되돌림, 이미 적용됐으면 `땅그림_v2`를 보고 멈춤)

### 5-1. 적혈구 발판 (사용자 승인)
- 대상: `설계도 지형`의 지형 30, 31, 38~59
- 적혈구 그림(1137×451, 비율 2.52:1)에 맞춰 발판 **가로를 2.35로 자름**(가운데 기준, 콜라이더도 같이). 위치·높이는 그대로
- 지형 31(8.0 길이)은 적혈구 3개로 나눔: 원래 오브젝트 = 가운데, `지형 31-2`, `지형 31-3` 새로 추가
- 원래 회색 SpriteRenderer는 끄기만 함, 그림은 자식 `그림`

### 5-2. 빨간 블록에 땅 그림 (사용자 승인, 여러 번 수정됨)
- 대상: 지형 01~29, 32~37 (벽과 천장 01~14 포함, 사용자 선택: "벽과 천장까지 전부")
- 최종 방식(v2):
  - 같은 높이 + **서로 붙어 있는 블록끼리 한 줄(run)**로 묶어 그림을 길게 이어 깔고, 블록 모양 **Sprite Mask**(Custom Range)로 파냄 → 구덩이에서만 끊겨 보임
  - 그림 종류는 줄마다 **AI 타일 → 땅1 → 땅2** 순서로 돌아감 (사용자 선택: "구덩이에서 바꾸기")
  - AI 타일은 한 장 건너 **좌우 반전**해서 같은 무늬가 그대로 연속되지 않게
  - 땅1/땅2는 둥근 양 끝 200px을 sprite border로 두고 Tiled로 가운데만 반복, 둥근 끝은 블록 밖(3유닛)으로 뺌
  - 블록이 그림보다 깊은 부분은 그림 아랫부분과 같은 색의 `땅바탕`으로 채움 (세로로 쌓으면 줄무늬가 생겨서)
  - 마스크 위쪽 여유 0.6 (윗선 위 혹이 잘리지 않게)
  - 벽과 천장은 그림을 위아래 뒤집어 검은 선이 아래(플레이어 쪽)로
  - 이전 버전 결과(`땅그림_이어붙임`, 블록마다 `땅마스크`/`땅바탕`)는 지우지 않고 **꺼 두고 이름 뒤에 `(이전)`** 붙임
- 정렬 순서: 땅 그림 -10부터 줄마다 -3씩, 혈류 -800, 원경 -1000/-1001

### 5-3. 혈류 (사용자 승인, 기획서 기준)
- 바닥이 없는 낭떠러지 3곳 = 혈류 구간: x **70.03~83.90**, **106.0~125.73**, **143.59~202.59**

## 8. 남은 작업

1. **예전 회색 블록 섹션 끄기** (허락 대기): 메인 씬 `Map_순환계/1_시작혈관` ~ `10_거대한문`(내가 예전에 만든 그레이박스)이 아직 켜져 있고, 팀원 설계도 지형과 겹쳐 정렬 순서 0으로 **새 땅 그림 앞에 그려짐**. 지우지 말고 SetActive(false)로 끄는 걸 제안했음.
2. **메인 씬 화면 점검**: v2 적용 결과를 사용자가 저장했음. 실제 화면에서 어색한 곳이 남았는지 다시 확인 필요. 특히
   - 구덩이에서 그림이 바뀌는 곳, 천장/벽 뒤집힌 그림, 혹 잘림, 기둥 바탕색
   - 씬에 `혈류 2 (2)`, `땅마스크 (1)`, `땅바탕 (1)`, `그림 (1)` 같은 **복제본**이 있음 → 사용자가 Ctrl+D로 만든 것인지 확인 필요

## 11. 참고 / 주의사항

- Unity 씬 YAML은 한글 이름을 `"땅그림"`처럼 이스케이프해서 저장함. grep할 때 주의
- Windows PowerShell 5.1은 BOM 없는 UTF-8 한글 스크립트를 깨뜨림 → `.ps1`은 BOM 포함 UTF-8로 저장, 또는 Bash 사용
- git push는 처음에 GitHub 로그인(브라우저)이 필요했음 (Git Credential Manager)
- 팀원 커밋이 `TagManager.asset`(태그/Sorting Layer)을 리셋한 적이 있음 → 태그 `Ground`, `CheckPoint` 등과 Sorting Layer가 사라지면 확인
- 병합 충돌 표시(`<<<<<<<`)가 커밋된 적이 있음(CheckPoint.cs, TagManager) → pull 후 컴파일 에러부터 확인
- 사용자 메모리(로컬)에 저장된 규칙: 한국어 설명, 학기 동안의 작업 공간, 씬 작업 규칙(1장)
